# 深夜食堂料理圖鑑

日劇《深夜食堂》的粉絲向料理筆記網站：每道料理一頁，標示出現在第幾部第幾集，並附上家庭做法。非官方、不使用劇照。
每新播出一集便可以按照同一套格式新增料理頁。

- 純 HTML / CSS / JavaScript，無需安裝或建置，可直接部署到 GitHub Pages。
- 專案規則寫在 [`CLAUDE.md`](CLAUDE.md)：AI 讀完後即可依同一套格式新增料理頁。

## 新增一道料理

1. 查證料理出現的部與集。
2. 在 `data/dishes.js` 加一筆資料。
3. 複製 `dishes/_template.html` 為 `dishes/<id>.html` 並填寫四個段落。

首頁卡片、篩選按鈕、集數標示會自動更新。詳細規則見 `CLAUDE.md`。
